Le favori pour Salesforce

Un clic sur la fiche : la bulle trouve le numéro tout seul. Rien à installer, c'est un simple favori.

Fuseau ← glisse ce bouton dans ta barre de favoris

Le favori n'a pas pu être chargé. Ouvre cette page depuis son adresse en ligne (pas depuis un fichier).

  1. Affiche la barre de favoris : Ctrl+Maj+B.
  2. Glisse le bouton noir Fuseau dans la barre.
  3. Sur une fiche Salesforce, clique sur Fuseau. La bulle se ferme avec Échap ou ×.

Si le glisser ne marche pas : , puis clic droit sur la barre de favoris → Ajouter une page…, nom « Fuseau », colle le code dans « URL ».

Pour appeler : clique sur le numéro corrigé (il se sélectionne), puis clic droit → Call comme d'habitude. Ou bouton Copier. Si le favori ne trouve pas le numéro, sélectionne-le à la souris avant de cliquer.

Lire le résultat

Entre 9h et 18h chez le client : on peut appeler.
Ça ouvre dans moins d'1 h 30 : l'heure de rappel est indiquée.
Trop tôt ou trop tard : rappel indiqué en heure de chez toi.

Sans indicatif, un numéro peut exister dans plusieurs pays. Fuseau affiche le plus probable avec un pourcentage (selon votre clientèle : France, Canada, USA, Suisse, Belgique, Luxembourg, outre-mer…) et les autres possibilités en dessous.

Tout est calculé dans ton navigateur : aucun numéro n'est envoyé nulle part.
